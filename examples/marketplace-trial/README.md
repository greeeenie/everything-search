# Примеры тестового ru-marketplace-mcp

`tools.json` содержит 35 инструментов реально установленной версии 2.9.3 с исходными описаниями и схемами. Поле `upstream_commit` указывает проверенную ревизию. Условия MIT для экспортированных описаний приведены в `LICENSE-upstream.txt`.

`smoke.json` содержит сокращённые результаты 11 реальных MCP-вызовов, включая доступность десяти выбранных площадок и общее сравнение. Поля `sample` представляют первые две исходные карточки, они могут относиться к соседним моделям. Числовой минимум сравнения в этом прогоне выбрал ToGo Pro при запросе Vali 1 Pro, что требует проверки модели перед рекомендацией.

`cards.json` содержит чтение двух карточек Ozon и двух карточек AliExpress. Исключены транспортные поля характеристик Ozon. Цены относятся ко времени запроса. У Ozon `price` является обычной ценой, `card_price` банковской. AliExpress в карточках вернул `price_rub=null` с предупреждением о незагрузившемся модуле цены.
