# Проверка развёртывания 14 ноября 2026

## Работающая инфраструктура

Research размещён на `multitool.local` в `/opt/research-v2`. Хост имеет 3795 MiB RAM, четыре ядра ARM64 и около 47 ГБ свободного места на момент установки. На Pi работают MCP, SearXNG, SQLite, Crawl4AI и одностраничный Chromium worker.

EU использует существующий Xray SOCKS5 `127.0.0.1:10808` и латвийский VPS. RU использует домашнего российского провайдера через независимое правило для UID Research. Диагностический инструмент подтвердил различные внешние IP и страны RU/LV.

Pi установил исходящее SSH-соединение за домашним NAT. На VPS обратный forwarding слушает `127.0.0.1:8766`, socket relay слушает `127.0.0.1:8765`. Существующий Secure MCP Tunnel подключён к этому relay. Проверены его readiness и список из десяти MCP-инструментов через VPS. Установленный в ChatGPT Research успешно выполнил `search_web` и `search_hacker_news` после переключения.

Пять сервисов Research и timer на Pi имеют состояние active/enabled. На VPS включены Secure MCP Tunnel и relay socket. Конфигурации Xray и sing-box на Pi совпали с контрольными суммами резервных копий, их процессы сохранили PID 1155 и 1156 в ходе установки. Xray/x-ui на VPS сохранил PID 529719. Действующий европейский VPN-выход подтверждён реальными запросами.

Через установленный Research в ChatGPT выполнен `search_web`, получена подтверждённая страница Python через EU. Для новых инструментов сервер публикует десять схем, существующее подключение ChatGPT требует обновления списка инструментов через Refresh.

Комплексный quick-запрос по Wanbo Cube 2 Pro вернул 18 предложений и частичные веб-результаты за 30.4 секунды с `timed_out=true`. Для незавершённого web-компонента указано `time_budget_exceeded`. Среди ограничений источников наблюдались timeout и robots_denied. Привязка отзывов к модели проверяется синтетическими тестами.

При проверке закрытых портов учитывался ответ прикладного протокола. Прозрачный VPN на пути рабочей станции способен подтвердить TCP-соединение до проверки конечного сервиса, поэтому один успешный connect не используется как доказательство публичной доступности.

## Доступность российских площадок

Проверки выполнялись по реальным индексированным карточкам Wanbo Cube 2 Pro через RU.

| Источник | Результат |
|---|---|
| Ozon | Публичная карточка и браузерная проверка получили HTTP 403 |
| Avito | Chromium автоматически выполнил вычислительную проверку, получены выдача и отдельное объявление |
| Яндекс Маркет | Публичная выдача HTTP 200, извлечены предложения из видимой разметки |
| DNS | В одной публичной проверке получено требование авторизации |

Через обычный MCP-вызов `search_products` получены 18 подтверждённых предложений Wanbo Cube 2 Pro, десять с Avito и восемь с Маркета. Идентификатор нормализованной модели общий. Cube 1, X5 Pro и предложения комплектов отфильтрованы. Ссылки ведут на отдельные объявления и карточки с идентификатором предложения Маркета. Количество отражает конкретную проверку и может меняться.

Цены Маркета в этой выборке имеют условие оплаты картой Яндекс Пэй. Состояние товара в выдаче Avito остаётся `unknown`, если площадка его явно не указала. Отдельная карточка Avito вернула подтверждённые цену, наличие и `NewCondition`. При поиске с `condition="used"` проверены четыре объявления, получено одно подтверждённое б/у предложение. Доставка в Омск остаётся `unconfirmed`, победитель по полной стоимости сохраняет `null`.

Первоначальный вывод о запрете всех карточек Маркета возник из-за стандартного RobotFileParser, который преобразовывал правило `Disallow: /?` в запрет `/`. Переход на Protego и регрессионные тесты исправили обработку. Для Ozon добавлены ограниченные перенаправления robots.txt и анонимные cookie. Лимит HTML увеличен до 8 МБ, поскольку реальная карточка Маркета превышала 2 МБ. Транспортные JSON-блоки noframes исключены из текстовых фрагментов.

Автоматическое выполнение проверок доступа включено после явного разрешения владельца. На Avito подтверждён JavaScript/PoW-протокол. На Ozon проверены обычный Chromium и отдельный диагностический запуск Patchright с виртуальным экраном Xvfb. Запрос `/abt/result` получил 403, подтверждённые цены Ozon отсутствуют. Xvfb установлен на Pi для диагностики, рабочий сервис использует headless Playwright. Графический CAPTCHA-решатель отсутствует.

Реальные страницы и диагностические снимки хранятся в игнорируемом `artifacts/private`. В репозиторий включены сокращённые ответы и синтетические регрессионные примеры. `scripts/ru_marketplace_smoke.py` проверяет автоматическое чтение Avito, карточки Ozon/Маркета, поиск на трёх площадках, сравнение и фильтрацию бывших в употреблении товаров.

SearXNG вернул релевантные ссылки на товары и страницы документации. DuckDuckGo был отключён после наблюдавшейся CAPTCHA. В конфигурации используются бесплатные web-движки, отдельные провайдеры могут отвечать 429 или временно приостанавливаться. Ошибки поиска имеют ограниченный TTL.

## Версии и ограничения проверки

SearXNG установлен из commit `219b63b207c98b85471de5abab773e76432f1961`. Основные проверенные версии включают MCP 1.30.0, HTTPX 0.28.1, Crawl4AI 0.9.5 и Playwright 1.65.2 на Pi. Приложены pyproject.toml, uv.lock и конфигурация развёртывания.

Docker Compose проверен как конфигурация YAML. Выполнение контейнерного варианта остаётся непроверенным, рабочее развёртывание использует systemd. Полный reboot обоих устройств остаётся непроверенным. Подтверждены boot enable, корректность units, перезапуск приложений и автоматическое восстановление SSH.

Ядро Pi возвращает MemoryCurrent как `[not set]`. MemoryMax задан в unit-файлах, фактическое применение ограничений memory cgroup требует отдельной проверки ядра. Ограничение Chromium одной страницей действует на уровне приложения. После живых проверок оставалось около 2.9 ГБ доступной памяти.

Извлечение цен использует schema.org Product/Offer, microdata Avito и видимые карточки выдачи Маркета. Покрытие нестандартной разметки ограничено. Отзывы представлены вложенными schema.org Review и фрагментами обсуждений с точным именем модели. Подлинность отзывов и владение товаром авторами остаются неподтверждёнными.

Поиск партнёрского API Маркета удалён 22 июня 2026 года. Реализация получает публичные страницы. [Изменения партнёрского API](https://yandex.ru/support/market-distr/ru/api/concepts/changelog)

Новые инструменты и параметры загружаются в ChatGPT через Refresh установленного Research. Старые четыре инструмента продолжают обслуживаться через существующее подключение.
