# Проверка ru-marketplace-mcp 16 ноября 2026

## Развёртывание

На Raspberry Pi установлен чистый upstream `Vladimir-Human/ru-marketplace-mcp`, версия 2.9.3, commit `f019e9ac41555c8509d50777cbafa0ab37fec8c5`. Проверен пустой `git status`. Зависимости установлены по `uv.lock` в отдельное окружение. Используется системный Chromium 156, отдельный пользователь и анонимный профиль. Для Ozon включена предусмотренная авторами настройка `OZON_CHROME_COMPAT=windows`.

Выбраны десять товарных площадок и сравнение, сервер публикует 35 инструментов. Службы MCP, Chromium, российского выхода и обратного SSH включены для автозапуска. Новый профиль выходит через домашнего российского провайдера. Приватные MCP/CDP-порты привязаны к loopback.

Research переключён на тестовый сервер через существующий Secure MCP Tunnel. На VPS проверены MCP initialization, список 35 инструментов и readiness 200. Запрос без авторизации отклонён, запрос с bearer и tenant успешен. Старый сервер доступен для отката через `link.py vps-rollback`. Для загрузки нового списка в ChatGPT требуется Refresh подключения.

## Ограничения сравнения

Запрос `compare_prices` по Wanbo Vali 1 Pro с четырьмя источниками и `in_stock_only=true` вернул `complete=true`, 20 исходных предложений и исходы всех четырёх площадок. Фильтр исключил из ранжирования 12 предложений с неопределённым наличием. Цены WB Wallet исключены из обычного ценового ранжирования.

При этом `cheapest` и `cheapest_comparable` выбрали Wanbo ToGo Pro с Яндекс Маркета. Название соответствует другой модели. Получение данных работает, точность выбора модели в общем сравнении требует дополнительной проверки на стороне клиента. Этот результат зафиксирован в примере, числовой минимум нельзя использовать как готовую рекомендацию по Vali 1 Pro.

В проверенной карточке Ozon `2229449678` название содержит Wanbo Vali 1, обычная цена составила 28 265 ₽, банковская 25 438 ₽. Карточка `6352256373` имеет название Wanbo Projector Vali 1 Pro синий, обычную цену 56 522 ₽ и банковскую 50 870 ₽. Это наблюдения отдельных предложений, ассортимент всего Ozon ими не исчерпывается.

В тестовых профилях отсутствуют пользовательские аккаунты площадок. Графические проверки доступа и требование входа остаются ограничениями чистого upstream. Полная перезагрузка новых служб вместе с устройствами остаётся непроверенной, проверены включение автозапуска и перезапуск тестовых процессов.

Полные приватные снимки находятся в `artifacts/private`, сокращённые результаты и схемы инструментов в `examples/marketplace-trial`.
